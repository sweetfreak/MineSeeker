# MineFind Puzzle Game

MineFind is an SwiftUI-inspired reimagining of the classic mine-finding puzzle game. It was created in 

xCode using SwiftUI. 

## Built With
- Swift
- SwiftUI
- Vortex [(a particle effect library by twostraws)](https://github.com/twostraws/Vortex)

## Get started
You can find MineFind on the iOS App Store in the US and Canada. It's available on iPhone, iPad, Mac, and even Vision Pro

## Features

MineFind has three options for difficulty (mine frequency) and three options for minefield size, however that number increases to 4 when played on larger screens (IOW, not on iPhones)

MineFind connects directly uses GameKit to connect directly to GameCenter - more features using this connection are on the way!
